# E-Commerce Purchase Intent React Frontend

Modern React 18 + Vite + Tailwind CSS analytics dashboard and ML prediction interface for IDRA Capstone Project #10.

## Tech Stack

- React 18 & Vite
- Tailwind CSS
- Recharts (Data Visualizations)
- Lucide React (Icons)
- Axios (API Service)
- React Router DOM

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the Vite development server:
   ```bash
   npm run dev
   ```

3. Open in browser:
   `http://localhost:5173`

Ensure the FastAPI backend is running on `http://127.0.0.1:8000`.
